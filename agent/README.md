## დონე 1: Routines (მუშაობს ახლა)

თითო Routine-ს აქვს **მუდმივი სესია** (`agromart-agent` ტეგით), რომელშიც რეპოზიტორია უკვე ჩამოტვირთულია და წინა ანგარიშები ინახება შედარებისთვის. ყოველ გაშვებაზე სესია ბრანჩს აახლებს, კითხულობს `.claude/skills/agromart/SKILL.md`-ს და `agent/routines/<name>.md`-ს, ასრულებს და ბოლოს push შეტყობინებას აგზავნის. ინსტრუქციის შესაცვლელად საკმარისია `.md` ფაილის რედაქტირება და push.

> ერთჯერადი სესიები (create_new_session_on_fire) რეპოზიტორიის გარეშე ეშვება და `add_repo` არ აქვს, ამიტომ არ გამოიყენება. Routine-ები შენი Claude-ის ლიმიტიდან იხარჯება: 5-საათიანი ლიმიტის ამოწურვისას გაშვება ჩავარდება (2026-10-04-ის პირველი გაშვება ასე ჩავარდა).

## დონე 2: რეალურ დროში მომუშავე აგენტი (ამოცანები 6–8)

```
Telegram (მფლობელი) ─┐
Messenger / Viber ───┤
საიტი: ჩატი, შეკვეთა ┼─▶ n8n ─▶ Claude Managed Agent ──▶ ინსტრუმენტები
Meta კომენტარი ──────┘           │ მეხსიერება               Supabase · Meta Graph API
                                 │ agromart სქილი            Westore.ge · Gmail · ვებ-ძიება
                                 ▼
                     Telegram: ✅ / ❌ / ✏️ ყოველ გარე ქმედებაზე
```

ნებართვები (Managed Agents permission policy):

| ქმედება | პოლიტიკა |
|---|---|
| კითხვა, ძიება, ანალიზი, დრაფტი | `always_allow` |
| FAQ-ზე პასუხი (ცოდნის ბაზიდან, ზუსტი დამთხვევა) | `always_allow` + ლოგი |
| პოსტი, კლიენტისთვის არასტანდარტული პასუხი, შეკვეთის გაგზავნა | `always_ask` → Telegram ✅ |
| ფასის/მარაგის შეცვლა, გადახდა, ხელშეკრულება | აკრძალულია (ინსტრუმენტი არ არსებობს) |

### გასაშვებად საჭიროა მფლობელისგან

| რა | სად ჩაიწერება |
|---|---|
| Anthropic API key | Supabase secrets / Managed Agents vault |
| Telegram bot token (@BotFather) + შენი chat id | n8n credentials |
| Meta Page Access Token (`pages_manage_posts`, `pages_messaging`, `pages_read_engagement`) | vault |
| Supabase პროექტი (URL + service key) | vault |
| n8n ინსტანსის URL + API key | ამ გარემოს ცვლადები, თუ აქედან უნდა ავაწყო workflow-ები |
| Westore.ge-ს API ან შეკვეთის ფორმატი | n8n |

როცა ეს მზად იქნება, აგენტის კონფიგურაცია (`agent.yaml`), n8n workflow-ები და Telegram-ის დადასტურების ბოტი ამ საქაღალდეში დაემატება.
