1. **მომზადება:** Routine ეშვება მუდმივ სესიაში, სადაც რეპოზიტორია `vtiflis-web/ag` უკვე ჩამოტვირთულია. ყოველ გაშვებაზე ჯერ განაახლე: `git fetch origin claude/facebook-page-setup-58huzi && git checkout claude/facebook-page-setup-58huzi && git reset --hard origin/claude/facebook-page-setup-58huzi` (ლოკალური ცვლილებები არ გვჭირდება). თუ რეპოზიტორია სამუშაო საქაღალდეში ვერ იპოვე, ეს ერთ ხაზად ჩაწერე ანგარიშში და გაჩერდი.
   - შემდეგ წაიკითხე `.claude/skills/agromart/SKILL.md` და მიჰყევი. Claude Docs-ის დოკუმენტების ასლები: `agent/context/` (connector-ები Routine-ში არ არის).
   - წინა გაშვებების ანგარიშები ამავე სესიაშია: გამოიყენე შედარებისთვის („რა შეიცვალა წინა გაშვებასთან“), მაგრამ მონაცემები ხელახლა გადაამოწმე.
2. **ენა და ფორმა:** ქართული, ცხრილები, მოკლედ. ყოველ ციფრს: წყარო (ბმული) + თარიღი + ტეგი A/B/C/D.
3. **არ მოიგონო:** ვერ მოიძიე → „მონაცემი ვერ დავადასტურე“.
4. **გარე ქმედება აკრძალულია:** არაფერი გამოაქვეყნო, არავის მისწერო, ფორმა არ შეავსო, არაფერი იყიდო. არტეფაქტებს მხოლოდ კითხულობ, თუ ინსტრუქცია პირდაპირ სხვას არ ამბობს.
5. **კოდის ცვლილება:** რეპოზიტორიის ფაილები არ შეცვალო და არ დაფუშო, თუ ინსტრუქცია პირდაპირ არ ითხოვს.
6. **შედეგი:** სრული ანგარიში ამ სესიის ბოლო პასუხად; ბოლოს გაგზავნე PushNotification ერთი წინადადებით (მთავარი მიგნება ან „ცვლილება არ არის“). პირველი 3 ხაზი: **რა შეიცვალა**, **რა მოითხოვს გადაწყვეტილებას**, **რა ვერ შევამოწმე**. თუ არაფერი შეცვლილა, ასე დაწერე ერთ ხაზად.
7. **ხარჯი:** ძიება და კითხვა მიზანმიმართულად; 20–30 წყაროზე მეტი არ სჭირდება.
