# კონტენტ-ქარხანა (ყოველკვირეულად)

მიზანი: მომდევნო კვირის მზა კონტენტი agromart.ge-სთვის. მფლობელი მხოლოდ ამტკიცებს.

## ნაბიჯები

1. განსაზღვრე სეზონური აქცენტი მიმდინარე თარიღის მიხედვით (SKILL.md §3, Meta-ს სეზონი).
2. წაიკითხე `facebook/README.md` (9 პოსტი) და GHF დოკუმენტის არსებული პოსტები/კრეატივები (SKILL.md §6). **არ გაიმეორო.** გამოიყენე სხვა კუთხე: კონკრეტული მცენარე, სიმპტომი, მომხმარებლის კითხვა, „ფასი ქოთანზე“ გათვლა, სეზონური შეცდომა.
3. დაწერე **3 პოსტი** (FB/IG) და **2 რეკლამის ვარიანტი**:
   - პოსტი: ტექსტი (≤600 სიმბოლო), ჰეშთეგები (3–5), ვიზუალის აღწერა, ბმული `https://shop.agromart.ge/#<plan>`, გამოქვეყნების დღე/საათი (ორშ/ოთხ/პარ 19:00).
   - რეკლამა: Primary text, Headline (≤40), CTA, ad set (SKILL.md §3).
   - ყველა ფასი და დოზა მხოლოდ SKILL.md-დან. Meta-ს აკრძალული ფრაზები არა.
4. **ვიზუალი:** თითო პოსტზე 1080×1350 PNG, ბრენდის ფერებითა და შრიფტებით. გამოიყენე `facebook/source/render.cjs`-ის მიდგომა (HTML → Playwright → PNG) და `site/img/*.webp` პროდუქტის ფოტოები. ფაილები შეინახე სესიის სამუშაო საქაღალდეში `agent/out/content-<YYYY-MM-DD>/` და მიუთითე ანგარიშში.
5. **თვითშემოწმება გამოქვეყნებამდე:** ფასები = SKILL.md? დომენი shop.agromart.ge? „საუკეთესო/ერთადერთი“ არა? კანაფი არა? ქიმიური პესტიციდი არა?
