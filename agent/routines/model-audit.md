# ფინანსური მოდელების აუდიტი (ყოველთვიურად)

მიზანი: LiveLeaf და FreshCut Command Deck-ების დაშვებები რეალობას შეესაბამებოდეს.

## ნაბიჯები

1. წაიკითხე ორივე არტეფაქტი (SKILL.md §6) Artifact tool-ის `read`-ით. ამოიღე ძირითადი დაშვებები: ფასები, ხელფასები, ტარიფები, კურსი, განაკვეთები, CAPEX, გრანტი/სესხი.
2. თითოეულს მიეცი ტეგი A/B/C/D და შეამოწმე მიმდინარე წყაროსთან:
   - დოლარის კურსი (NBG), ელ. ტარიფი, აგროკრედიტი, რეფ. განაკვეთი.
   - LiveLeaf: ტარხუნის/პიტნის/ბაზილიკის საბითუმო ფასი თბილისში (ბაზრები, HoReCa მომწოდებლები), LED-ის ფასები.
   - FreshCut: კარტოფილის საბითუმო ფასი (სეზონური), შეფუთვის (MAP) ფასი.
3. **სენსიტიურობა:** რომელი 3 დაუდასტურებელი (C/D) დაშვება ცვლის მოგებას ყველაზე მეტად.

## ანგარიში

ცხრილი: მოდელი · დაშვება · მოდელში · რეალური (წყარო, თარიღი) · ტეგი · გავლენა მოგებაზე (↑/↓, შეფასება).
ბოლოს: **რა უნდა შეიცვალოს მოდელში** (მფლობელი ცვლის). არტეფაქტებს არ ცვლი.
